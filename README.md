# WORD QUEST 소개 덱

[word-quest-fywr.vercel.app](https://word-quest-fywr.vercel.app/) 를 소개하는 게임형 인터랙티브 슬라이드 덱입니다.

## 보기

`index.html` 을 브라우저로 열면 됩니다. 외부 리소스가 전혀 없는 **단일 파일**(폰트·QR·아이콘 모두 인라인)이라 그대로 공유·배포할 수 있습니다.

## 조작

- **다음 / 이전**: `→` `←` · `Space` · `PageUp/Down` · 화면 하단 버튼 · 터치 스와이프
- **처음 / 끝**: `Home` `End`
- **특정 장 딥링크**: `index.html#s=7` (7번 슬라이드로 바로 이동)

## 구성 (12장)

| # | 슬라이드 | 내용 |
|---|---------|------|
| 1 | 타이틀 | WORD QUEST · "틀린 단어가 보스가 된다" |
| 2 | 문제 | 단어 암기가 실패하는 3가지 '상태이상' |
| 3 | 해결 | 단어 공부를 RPG로 (Before → After) |
| 4 | 핵심 메커니즘 | 틀린 단어 = 보스로 재등장 |
| 5 | 학생 기능 | HP/MP/EXP · 콤보 · 스트릭 · 던전 |
| 6 | 단어 입력 | 사진 스캔(OCR) · 직접 입력 · 샘플 · 교사 배포 |
| 7 | 학습 설계 | 망각곡선 기반 간격 복습 (그래프) |
| 8 | 교사 기능 | 클래스 대시보드 · 실시간 진도 |
| 9 | 시작 방법 | 로컬 플레이 vs 구글 로그인 동기화 |
| 10 | 비교 | 보통 단어앱 vs WORD QUEST |
| 11 | 학습 루프 | 입력 → 전투 → 오답=보스 → 복습 → 클리어 |
| 12 | 마무리 | 지금 플레이 CTA · QR 코드 |

## 디자인

- **컨셉**: RPG 던전 / 레트로 아케이드 세계관 (의도적 다크 테마)
- **폰트**: 픽셀 폰트(Press Start 2P, HUD·로고·수치) + 한국어 산세리프(본문)
- **컬러**: 딥 퍼플/네이비 배경 · 골드(EXP) · 시안(MP) · 크림슨(보스/HP) 강조
